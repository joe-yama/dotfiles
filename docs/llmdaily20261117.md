## (a) TL;DR

### Swift 1.5 Flash-Next の評価 (詳細)

- **主張**: 「過剰な思考」に結びつくトークンにペナルティをかけ、RL と OPD で精度を戻した。xhigh 設定で GPQA の精度差は −0.2pt にとどまり、thinking トークンは平均 −55.8%、壁時間は約 1.8 倍速。学習にはエージェント / ターミナル / SWE 向けの post-training も含む。
- **第三者の測定 (1 件)**: r/LocalLLaMA の投稿者が独自の Aider 系エージェント・コーディング 107 問で比べた (2026-09-25、Q5 系 GGUF)。
  - 1 回目の正答率は 41.1% vs base 40.2%。リトライ込みは 86.9% vs 90.7%。McNemar の p ≈ 0.29 で有意差なし。
  - 1 問あたりのトークンは 6,991 vs 17,646、所要時間は 608 秒 vs 1,542 秒。
  - **品質はほぼ同等で、時間は約 4 割**という結果。最難問ではリトライで回復する率が低い (78% vs 84%)。
- **mlx-serve パック作者の A/B** (26.11.1、M4 Max 128GB、18 ケース × 5 回、逐次実行で交互ではない):
  - 品質スコアは 81.2 vs 84.4。instructions が 62.5 vs 100 (1 ケースの失敗)、structured が 62.5 vs 37.5。
  - MTP 込み decode は 57.8 vs 74.0 tok/s (**−22%**)。MTP なしの decode は −2.4%。
  - 64K 時点の prefill は 748 vs 414 tok/s。ただし作者自身が「キャッシュ状態が違う」と注記していて、この prefill 差は鵜呑みにできない (同じアーキテクチャで prefill が 1.8 倍になる理由が無い)。
- **ライセンス**: Swift Open License v1.0 (Apache 系に商用制限条項を足したもの)。**前会計年度の売上が 100 万ドル以上の法人 (グループ合算) による商用利用は許諾外**で、別途 Swift Enterprise License が要る。個人の非商用利用には制限が無い。opencode / dsh を業務に使っているなら、この条件に当たるかの確認が要る。

### 2. (任意) 本命枠の 3 者 A/B: 現行 4bit / ddalcu iQ-4.7bpw / Swift 1.5 mixed-4-8bit

前回の (e)-2 (ddalcu iQ の A/B) は未実施。今回の Swift を加えて、1 回の A/B で両方を判定することを提案する。前回の iQ 用エントリ案 (`qwen38-flash-next-iq`) はそのまま使う。

- **(a) リポジトリと形式**: `pgmharikrishnan/Swift1.5-Qwen3.8-Flash-Next-MLX-Serve-mixed-4-8bit` (rev 629259c、107.3GB、113 ファイル、非 gated、`library_name: mlx-serve`、`model_type: qwen4_exp`)。mlx-serve の `tests/convert_qwen38_flash_next.py` で変換されている。ngram_table.bin は mmap される方式。MTP ヘッドと vision タワーを同梱。
- **(b) 常駐**: 作者実測で 70.1 GiB (重み 75.3GB)。旧 ARC4NUM と同じ配分なので、preflight の必要空きは約 77GB と推定 (ARC4NUM 時代の閾値 77.1GB と同程度)。アイドル時の空き 99GB で足りる。推論中の wired ピークは 11-08 の無検閲枠 (最大 91.1GB) と同程度と見込む (未実測)。
- **(c) 期待 tok/s と品質**:
  - **素の decode は Flash-Next と同等** (作者測定で −2.4%)。**MTP の利得が小さい** (作者測定で +8%、Flash-Next は +35%)。当機の MTP on の short は、11-08 の同配分パック実測 (72.8〜76.1) より 1〜2 割低い 60 前後と推定する (未実測)。
  - 一方で thinking トークンが約 4〜6 割減るので、**1 タスクあたりの壁時間は 0.4〜0.6 倍になる可能性がある** (第三者の Aider 測定で 0.39 倍)。
  - 品質は、自己申告で TB2.1 +2pt / LCB +2pt / IFBench −3pt。第三者測定では有意差なし。
  - 量子化は imatrix 無しの mixed なので、BF16 比 KL は旧 ARC4NUM と同じ水準 (約 0.18) と推定する。ddalcu iQ (0.066) より量子化誤差は大きい。
